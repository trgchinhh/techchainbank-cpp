# Chương trình cơ bản mô phỏng tính năng và ứng dụng của blockchain trong ngân hàng bằng C++

-----

## Các tính năng:
```
Tên: TechChainBank (Techology BlockChain Banking)

Menu: 
    + Đăng nhập và đăng xuất 
    + Nạp tiền 
    + Chuyển tiền và đóng thành block 
    + Xem số tài khoản 
    + Xem Qrbank
    + Xem lịch sử giao dịch
    + Xem blockchain 
```

## Thư mục:
```
├── src
│   ├── lib
│   │   ├── json.hpp
│   │   ├── picosha2.h
│   │   ├── qrcodegen.cpp
│   │   └── qrcodegen.hpp
│   ├── block.json
│   ├── blockchain.cpp
│   ├── blockchain.h
│   ├── caidat.cpp
│   ├── chuongtrinh.cpp
│   ├── data.json
│   └── thuvien.h
└── README.md
```

## Biên dịch và khởi chạy
```bash
git clone https://github.com/baoxipo/techchainbank-cpp.git
cd techchainbank-cpp
g++ ./run.cpp -o ./run.exe
./run.exe
```
